# xizi-array pilot

This pilot materializes six four-class questions from one heap-writing array
program. `questions.json` maps public candidate/mutant artifacts; `gold.json`
is evaluator-only and must never be copied into an agent workspace.

The six labels are balanced as follows: two `perfect`, two `sound`, one
`complete`, and one `incomparable`. They follow the fixed ordering for base
program zero in the 600-question construction plan.
