# Multi-base harder classification pilot

Five independent, classification-only questions:

- multi-callee binary-string addition over several heap buffers;
- a closed 3-by-4 matrix structure specified through relational summaries;
- a four-node doubly-linked queue transformed through helper calls;
- IEEE-754 batch clamping with NaN and signed-zero observations;
- stable destructive merge with node identity and a provenance trace.

The OpenHands workspace receives no `gold.json` and no TeSpec executable.
