# Multi-base hard classification pilot

Five independent, classification-only questions:

- nested-loop/dynamic-allocation sorting;
- recursive composition of arrays, SLL, and DLL heaps;
- a large closed filter structure with coupled arithmetic updates;
- byte-array checksum modulo machine width;
- a callee-driven loop over a doubly-linked heap.

The OpenHands workspace receives no `gold.json` and no TeSpec executable.
