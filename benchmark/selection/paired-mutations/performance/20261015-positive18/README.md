# 18 个正例的 CN / QCP / Fulminate / teSpec 实测结果

共 18 个正例、85 组冻结输入。自动阶段逐程序串行运行 3 次，以下时间为中位数；模型补证及其检查记录实际全部尝试成本。四项 QCP 模型补证均完成，假设审计均为 Closed under the global context，且逐项通过独立 coqchk。

配置模型为 **gpt-6.1-sol**，共实际调用 8 次（每项 2 次，含失败和修复）。输入 475,350 token，输出 3,549 token，总计 **478,899 token**；输入中的 322,048 token 为缓存命中，已包含在输入总数中。teSpec 本批全部由自动阶段 PASS，模型 token 为 **0**。

单位：时间为秒，内存为 MiB。完整逐项字段见 program-metrics.csv，原始回执、日志和证明保留在同目录。

## 口径与复现

CN/QCP 是所列目标函数的全输入验证，Fulminate/teSpec 是冻结输入上的测试，四列不是同一种覆盖保证。原文件名带 broken 的来源已经修复为本批正例。

内存是各阶段/各轮中最大的单进程驻留峰值，Linux 使用 /usr/bin/time %M；模型客户端使用 Windows PeakWorkingSetSize。不是并发进程内存之和，不包含远程模型服务显存。模型客户端在 Windows，验证器在 WSL；环境和 ABI 见 summary.json。

早期 raw-results.json 是保留的预实验，最终自动数值仅来自 automatic-final/raw-results.json；其中使用阻塞 wait 和独立超时线程，避免超时轮询给毫秒级程序引入延迟。模型首轮失败的证明、编译诊断、token 和时间均保留，不能只统计成功一轮。

源码和基线规约未因性能结果改变。每个正例原始文件及 CN/QCP 哈希见 ../.. 的 manifest.json。模型证明 Goal 与原生 QCP 导出的原始 VC 逐字哈希对应；未复用此前已完成的 proof 作为本次模型生成结果。

测量脚本及模型/检查入口快照位于 drivers/。模型调用需要现有 Codex 登录；运行库需匹配 Coq 8.20。计时仅保证本实验内部串行，不宣称整台机器独占或操作系统冷缓存。
