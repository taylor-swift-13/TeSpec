# read：逐次执行的 ITP 测量

12 次产生 UNKNOWN 的测试执行各有一个独立任务，每个任务仅提供该执行的原始目标和已检查的具体堆辅助库。该次的原始出口反证、空间拆分反证和入口可满足性证明合为一次 ITP。

每次独立计量 gpt-6.1-sol 填写证明（含失败修复）、辅助库／目标／候选编译与假设审计、完整独立 coqchk。所有尝试分别保留回执，峰值内存取实际各进程峰值，不按次数均摊。辅助库源码复用但每次单独编译并计费。未复用其他输入的候选证明。已有原生测试执行记录通过源码、输入及执行器哈希匹配后复用。

`execution-NN/receipt.json` 保存单次的实际成本及原始测试绑定。根 receipt.json 和 statistics.json 保存汇总审计数据，正式展示见 ../tespec/itp-average.md，只展示逐次实测的算术平均值。旧 20261015-itp-metered 共享批次保留为历史，不计入本次。
