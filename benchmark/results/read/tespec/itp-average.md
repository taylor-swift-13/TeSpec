# read ITP 平均开销

12 次测试执行各自独立调用 agent、编译并做内核检查；同次执行的全部待处理 VC 合计为一次 ITP。以下展示逐次实测的算术平均值，含重试开销。

| 项目 | 每次测试执行的平均值 |
|---|---:|
| agent 填写证明 | 69.9816 秒 |
| Coq 编译与审计 | 4.1723 秒 |
| 独立内核检查 | 127.0494 秒 |
| ITP 合计 | 201.2033 秒 |
| 输入 token | 126648.00 |
| 输出 token | 1231.33 |
| 总 token | 127879.33 |

模型 gpt-6.1-sol。内存不按次数相除；每次执行的原始资源和完整回执保留供审计，旧共享批次仅作为历史。
