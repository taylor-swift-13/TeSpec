\section{Checking Stateful Instances}
\label{sec:approach}
Figure~\ref{fig:overview} follows a test through three stages: select an
instance, execute under the selected strategy while recording observations, and discharge
the resulting propositions. The execution strategy supplies states; the oracle
supplies evidence about those states and retains their execution scope.

The running example first illustrates body execution and copied observations;
we then describe modular continuations and the shared oracle.

\subsection{Select an instance and execute its bodies inline}
Typed bindings specialize the root precondition. Binding $x$ to 13 can
leave the address $p$ symbolic. The entry checker establishes that the
selected domain contains a state, using automatic reasoning or an
existential Rocq obligation. Execution retains the entire domain.
An existence witness certifies nonemptiness without selecting the sole
heap to execute.

\tespec{} reuses \qcp{}~\cite{wu2026qcp} to evaluate expressions, update symbolic heaps,
and generate arithmetic and memory-safety obligations.
Known guards select a successor; unresolved guards retain each successor
whose infeasibility has not been established.
Calls execute available bodies with fresh parameter slots and logical
entry bindings. Shared writes and the actual return value survive the
call; callee-local slots are retired. Loops execute their conditions and
bodies, including \texttt{break}, \texttt{continue}, and early return.
An exhausted resource bound records an incomplete execution.

For example, a helper that increments a cell from 3 to 4 leaves the
caller with 4 even if its contract promises only some integer greater
than 3. The contract is checked against the computed state. The concrete
value remains available to subsequent operations.

\subsection{Inline observations preserve reached states}
\label{sec:boundaries}
At a selected boundary, let $P$ describe the reached state and $A$ the
resolved annotation. The checker records
\[
                 P\vdash A*F_{P,A}
\]
on a logical copy and continues with $P$.
Figure~\ref{fig:observation} shows the consequence: changing the least-root
assertion changes its VC while the same write and return still follow.
The copy is a logical snapshot, not a runtime duplication of the heap.

\paragraph{Resolve the observed footprint.}
Scalar C locals occupy owned cells. An auxiliary annotation may omit
unrelated local slots, so $F_{P,A}$ contains exactly those eligible
slots, with their types and current values.
Resolution exposes local addresses before framing, including a local
pointer that aliases another local, to avoid counting a cell twice.
User-owned cells omitted by an assertion remain observable obligations.
For a mask $m$ selecting local cells, exact heap decomposition gives
\[
 (A*\mathit{exact}(h_m))(h)\Longleftrightarrow A(h_{\neg m}).
\]
The mask may depend on an existential witness. Resolution retains the
witness choices; refuting one choice does not refute all of them.

\paragraph{Record the selected boundaries.}
The schedule identifies function, loop, and intermediate observations.
The two observation schedules are independent of the execution strategies
in Section~\ref{sec:strategies}. The richer schedule additionally checks
selected internal annotations.
Named contract alternatives are resolved by explicit routing or retained
as a disjunction. An unresolved boundary match records incomplete coverage.
The formal observation inventory in Section~\ref{sec:semantics} connects
this schedule to the checks actually emitted.

\subsection{Discharge and aggregate evidence}
\label{sec:evidence}
Figure~\ref{fig:result-flow} separates evidence for a VC from evidence
for an execution. Automatic entailment first attempts each frozen original
obligation. SMT procedures can combine separation constraints with
background theories~\cite{piskac2013smt,reynolds2016sl}.
Our SMT route searches for a model of the negated obligation; the optional
\texttt{--spatial-smt} mode encodes supported memory predicates.
UNSAT establishes validity under the encoding interface.
SAT establishes invalidity after checking the model in the original
interpretation. An unconfirmed model or unresolved query enters proof
completion.

The agent or developer receives the original proposition $\phi$ and can
construct a proof of $\phi$ or $\neg\phi$. Rocq checks the candidate,
and the dependency audit records its assumptions.
Separating proof search from acceptance also underlies \mbox{CoqHammer}
reconstruction and SMTCoq certificate
checking~\cite{czajka2018coqhammer,ekici2017smtcoq}.
All residual VCs from one test execution form one completion job, with
an individual result for each VC.
The manifest fixes source hashes, target interpretation, goal identity,
and proof polarity. The optional complete-certificate route also replays
automatically discharged goals and entry existence.

The evidence ledger then combines VC status with execution evidence.
A reachable violating state in the reported transition model establishes
path \fail{}; a feasible,
complete path whose required VCs are all valid establishes \pass{}.
Other paths remain \unknown{}.
At instance level, acceptance additionally requires a nonempty entry
and coverage of its executions. A single modular sample does not provide
coverage of all contract-admitted executions or prove reachability in the
replaced implementation.
An empty entry is reported with an invalid-instance reason.
Section~\ref{sec:semantics} gives the rules and their correctness arguments.
