\section{Instance Semantics and Guarantees}
\label{sec:semantics}
We distinguish constructing an execution tree, establishing its obligations,
and assigning a verdict. The body-execution model below applies to inline
execution with actual program transitions. A modular sampled tree instead
uses contract transitions; transfer to body execution requires the separate
correspondence in Section~\ref{sec:mode-correspondence}. A failed proof does not change execution, and a
refuted abstract obligation does not by itself establish an execution
counterexample~\cite{maksimovic2023exact}.

\subsection{Semantic objects}
A C configuration $\sigma=\langle\ell,\nu,h,\kappa\rangle$ contains its
control location, variable environment, owned heap, and call stack.
Frames retain their invocation's logical entry values.
A semantic state $z=(\sigma,\rho,\bar v)$ additionally records immutable
root bindings $\rho$ and labelled live logical values $\bar v$.
Auxiliary proof witnesses are not components of $z$.
The supplied transition relation $z\to_c z'$ preserves $\rho$ and updates
the remaining components according to execution.

Assertions use the interface syntax
\[
\begin{split}
 A::={}&p(\bar t)\mid\mathsf{emp}\mid t\mapsto_T u
       \mid A*A\mid A\land A\mid A\lor A\\
      &\mid\exists x:T.\,A\mid\forall x:T.\,A .
\end{split}
\]
A fixed interpretation $\Gamma$ supplies predicate definitions, typed
resources, and layout. Write $A(z)$ for satisfaction.
Ownership is exact: $\mathsf{emp}(h)$ means $h=\varnothing$, and
$(A*B)(h)$ requires $h=h_1\uplus h_2$ with disjoint components satisfying
$A$ and $B$~\cite{reynolds2002separation}.

\begin{definition}[Specification instance]
An instance is $I=\langle c,R,E,\theta,\mathcal B,\Gamma,b\rangle$:
a body, entry and return assertions, typed partial binding, observation
schedule, interpretation, and resource bounds. Its domain is
\begin{equation}
\begin{split}
\dom=\{z=(\sigma,\rho,\bar v)\mid {}&
 \mathsf{Entry}_c(z)\land\rho\models\theta\\
 &{}\land R(z)\}.
\end{split}
\end{equation}
$\mathsf{Entry}_c$ fixes the entry location and initializes the program
and live-value environments.
\end{definition}
An instance check quantifies over all of $\dom$. Establishing its
nonemptiness does not replace this domain by the existence witness.

Each source check has an identity $\alpha$ and an independent meaning
$\mathsf{Check}_\Gamma(\alpha,z)$: interpret its original annotation in the
current invocation, including the exact eligible local-storage frame.
Resolution must produce a predicate $Q_\alpha$ satisfying
\begin{equation}
\label{eq:resolution}
 \forall z\in S_N.\quad
 Q_\alpha(z)\ \Longleftrightarrow\ \mathsf{Check}_\Gamma(\alpha,z).
\end{equation}
Here $S_N$ is the represented state set defined below. This interface
preserves invocation bindings, all existential witness choices and their
frames, and user-owned resources. Acceptance uses the forward direction;
refutation uses the reverse direction.

\subsection{Candidate execution and observation rules}
A symbolic node $N=\langle\chi;P,\bar t,U,\Omega\rangle$ contains its control and invocation context $\chi$, an assertion,
live terms, pending check identities, and an append-only obligation inventory. Each record stores its check identity, source state predicate, and target predicate; its proposition is frozen when the record is created.
Its represented states use the joint denotation defined in
Section~\ref{sec:normalization}:
\[
\begin{split}
 S_N=\{(\sigma,\rho,\bar v)\mid {}&\sigma\sim\chi\ \land\ {}\\
             &\obs_\rho(P,\bar t)(\sigma,\bar v)\},
\end{split}
\]
where $\sigma\sim\chi$ fixes the represented control location and call
context. Thus normalization may change auxiliary witnesses while preserving
that context, root bindings, and live values.

The following rules construct a candidate tree; construction does not
assume its obligations are valid. Program execution uses
\[
\frac{U=[]\qquad
      \mathsf{Transfer}_c(N)=[N_1,\ldots,N_k]}
     {N\overset{\mathrm{exec}}{\Longrightarrow}\{N_1,\ldots,N_k\}} .
\]
Children inherit the obligation inventory and receive the observations
selected at their new boundaries.
Certification requires safety, progress, and successor coverage:
\begin{equation}
\label{eq:coverage}
\begin{gathered}
 \forall z\in S_N.\;
       \mathsf{Safe}(z)\land\neg\mathsf{Final}(z),\\
 \forall z\in S_N.\;\exists z'.\,z\to_c z',\\
 \mathsf{Post}_c(S_N)\subseteq\bigcup_i S_{N_i},
\end{gathered}
\end{equation}
where $\mathsf{Post}_c(S)=\{z'\mid\exists z\in S.\,z\to_c z'\}$.
Unresolved guards retain each successor not proved infeasible.
Coverage permits overapproximation.

At an observation, create the record
$e=(\alpha,S_N,Q_\alpha)$, whose proposition is
$\phi_e\equiv\forall z\in S_N.\,Q_\alpha(z)$.
The rule records $e$ without changing the continuation:
\begin{equation}
\label{eq:observe}
\frac{U=\alpha::U'\qquad Q_\alpha=\mathsf{Resolve}_{\Gamma}(N,\alpha)}
 {N\ \overset{\mathrm{obs}}{\Longrightarrow}\
  N[U\gets U',\ \Omega\gets\Omega\mathbin{\cdot}[e]]}.
\end{equation}
The field update preserves $\chi$, $P$, and $\bar t$. Neither $\phi_e$
nor its negation is a premise. Resolution faithfulness
(Equation~\eqref{eq:resolution}) is required when certifying the tree.

Write $N\equiv_JN'$ when only $(P,\bar t)$ changes and its joint
denotation is preserved pointwise for every $\rho$. Normalization uses
\[
 \frac{N\equiv_JN'}{N\overset{\mathrm{norm}}{\Longrightarrow}N'} .
\]
Therefore $S_N=S_{N'}$, retaining both the heap and its live values.

Administrative progress requires a well-founded rank decreasing on
every observation or normalization step between program transitions.
This is a reference-construction condition, independent of the
implementation's choice of resource bounds. Exhausting a bound creates an
\textsc{Unfinished} leaf. A \textsc{Done} node has no pending observations
and must establish safety, finality, $E$, and absence of outgoing
program transitions.

\begin{definition}[Boundary completeness]
Let $\mathsf{rec}_{\mathcal B}(z)$ list the selected pairs $(\alpha,z)$;
$\mathsf{Observe}_{\mathcal B}(\tau)$ concatenates them along $\tau$.
A concrete trace embeds in a tree branch by matching program steps to
execution edges and retaining its state across administrative edges.
Let $\Omega^{\rm obs}_\pi$ be that branch's ordered observation records,
counting each once. The projection $\mathsf{inst}_{\tau}$ replaces a
record $(\alpha,S,Q)$ by $(\alpha,z_i)$ at its matching observation edge.
The tree is boundary-complete when every complete embedded branch satisfies
\[
 \mathsf{inst}_{\tau}(\Omega^{\rm obs}_\pi)
       =\mathsf{Observe}_{\mathcal B}(\tau).
\]
\end{definition}
The state at each matched edge belongs to its record's source set.
List equality preserves check identity, order, and repeated loop visits.
Together with faithful resolution, it connects valid recorded propositions
to the original selected annotations.

\subsection{Oracle evidence and verdicts}
For an original obligation $j$, define
\[
\begin{aligned}
 \phi_j&=\forall z.\,S_j(z)\Rightarrow A_j(z),\\
 C_j&=\exists z.\,S_j(z)\land\neg A_j(z).
\end{aligned}
\]
$C_j$ is its classical countermodel query. A supported SMT encoding
$B_j$ and original-model validator must satisfy
\begin{equation}
\label{eq:oracle-interface}
\begin{aligned}
 C_j&\Rightarrow\exists m.\,B_j(m),\\
 \mathsf{Validate}_j(m,z)=\mathsf{true}
   &\Rightarrow S_j(z)\land\neg A_j(z).
\end{aligned}
\end{equation}

\begin{proposition}[Oracle soundness]
\label{prop:oracle-soundness}
Assuming sound solver answers and
Equation~\eqref{eq:oracle-interface}, UNSAT establishes $\phi_j$;
successful original-model validation establishes $\neg\phi_j$.
A kernel-checked proof establishes its checked polarity when its
statement denotes the original obligation and $\Gamma$ satisfies
its admitted dependency theory.
\end{proposition}
\begin{proof}
If $C_j$ held after UNSAT, the first interface condition would produce
a model of $B_j$, a contradiction. Validation supplies a state
satisfying $S_j$ and violating $A_j$, contradicting $\phi_j$.
The proof-assistant case follows from kernel soundness under the stated
interpretation of its dependencies.
\end{proof}
SAT without validated reconstruction, unsupported encodings, and
unsuccessful proof attempts establish neither polarity.
In particular, proving $\neg\phi_j$ need not construct a reachable model.

Entry uses the separate proposition $\exists z.\,z\in\dom$:
SAT means nonempty, and UNSAT means empty.
The executor's negative-entailment entry encoding has this meaning
under the explicit classical premise in \texttt{PreconditionOracle.v}.

For a branch $\pi$, let $F_\pi$ mean actual feasibility from $\dom$,
$K_\pi$ mean complete execution and selected checks, and $W_\pi$ mean
that a refuted safety, observation, or return VC has a validated
violating state reached at that check. With original VC results $v_j$,
\[
 V(\pi)=
 \begin{cases}
  \fail, & W_\pi,\\
  \pass, & F_\pi\land K_\pi
                  \land\forall j.\,v_j=\valid,\\
  \unknown, & \text{otherwise}.
 \end{cases}
\]
Rules have priority order: a reachable violation suffices despite other
unresolved obligations. Vacuous validity on an infeasible branch does
not establish a passing execution. Removing infeasible branches must
preserve coverage.

Execution errors retain separate diagnostics. Refuting a coverage or
normalization side condition prevents acceptance; it is not itself a
program violation.

\subsection{Reference guarantees}
\label{sec:noninterference}
The monitored judgment
$z\Longrightarrow_{\mathcal B}^{\tau,\omega}z'$
records a finite trace and its observations:
\[
\frac{}{z\Longrightarrow_{\mathcal B}^{[z],\,
                  \mathsf{rec}_{\mathcal B}(z)}z}.
\]
\[
\frac{z\to_c u\qquad
      u\Longrightarrow_{\mathcal B}^{\tau,\omega}z'}
 {z\Longrightarrow_{\mathcal B}^{z::\tau,\,
             \mathsf{rec}_{\mathcal B}(z)\cdot\omega}z'}.
\]

\begin{theorem}[Erasure and lifting]
\label{thm:erasure}
A state sequence $\tau$ admits a monitored derivation from $z$ to $z'$
if and only if it is a finite $\to_c$ trace between those states.
Every such derivation has
$\omega=\mathsf{Observe}_{\mathcal B}(\tau)$.
\end{theorem}
\begin{proof}
Induction on a program trace constructs a monitored derivation using
the singleton and step rules. Conversely, induction on a monitored
derivation retains exactly its program-step premises.
The same induction establishes the observation-list equation.
No rule tests an observation's truth.
\end{proof}
The theorem establishes reference trace preservation. Resource bounds
add a separate completeness check to the implementation.

\label{sec:verdicts}
\begin{theorem}[Nonvacuous instance acceptance]
\label{thm:acceptance}
Assume sound oracle evidence, a root representing exactly $\dom$, and
valid execution, normalization, and resolution interfaces.
If a finite boundary-complete tree without unfinished leaves receives
\pass, then $\dom\ne\varnothing$ and every maximal execution from $\dom$
terminates safely, satisfies $E$, and satisfies every selected observation.
\end{theorem}
\begin{proof}
Entry SAT supplies nonemptiness. Induct on tree height for a represented
state. Terminal obligations establish the \textsc{Done} case.
At an execution node, progress excludes stuck nonfinal states and
coverage places every successor in a child subtree.
Normalization preserves the joint state set; observation retains it
and establishes the recorded predicate by oracle soundness. Faithful
resolution transfers that result to the original annotation.
Each program step descends the finite tree, so an execution cannot have
more program steps than its height. Every maximal execution therefore
terminates. Boundary completeness identifies the discharged inventory
with every selected observation on that execution.
\end{proof}

A confirmed violation means
\begin{equation}
\label{eq:violation}
 \exists z_0\in\dom,z.\;
 z_0\to_c^*z\land\mathsf{Bad}_{E,\mathcal B}(z),
\end{equation}
where badness is unsafety, failure of a selected observation, or failure
of $E$ at return.

\begin{proposition}[Reachable-refutation soundness]
\label{prop:reachable-refutation}
Assume the resolution interface. A validated countermodel to a safety,
observation, or return VC establishes Equation~\eqref{eq:violation}
when an admitted trace reaches
it at the corresponding check. Such evidence excludes acceptance of
the same instance.
\end{proposition}
\begin{proof}
Validation supplies the violated predicate. Faithful resolution and
the matched check identity transfer this violation to the original check,
establishing badness. The trace supplies the initial state and
reachability. Acceptance would establish safety and the same selected
predicate at that state by Theorem~\ref{thm:acceptance}, a contradiction.
\end{proof}
The reachability condition is essential: an abstract endpoint may admit
$x=1$ and refute a requirement $x=0$ even when only $x=0$ is reachable.

\paragraph{Mechanized scope.}
The Rocq artifact proves parameterized finite-tree acceptance, trace
erasure and lifting, exact local framing, and preservation under licensed
normalization. It also formalizes entry polarity and scalar call/alias
properties. The rules in this section compose these interfaces at paper
level. Correct realization of transfer, resolution, the observation
schedule, and solver adapters is a premise of the implementation guarantee.
