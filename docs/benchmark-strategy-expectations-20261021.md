# 按执行策略区分预期，并消解 translation12（2026-10-21）

用户明确要求对 inline 和 modular 分别设置预期。array_load 的 original_client_translation12_only_entry 保留默认/inline PASS，新增 modular FAIL；这项修改针对原始弱合同客户端，不更改 C 程序、CN/QCP 规约、绑定或六个断言。其他用例继续沿用原预期。历史报告仍保留当时使用的统一 PASS，不回写历史实验。

## 预期格式

在 evaluation-plan.json 对应 case 中：

```json
"expected": "PASS",
"expected_by_execution_strategy": {
  "inline": "PASS",
  "modular": "FAIL"
}
```

只影响 teSpec 的对应执行策略，空间 SMT OFF/ON 使用同一策略预期。CN、QCP、Fulminate 不继承这个策略覆盖。没有该字段的旧用例按原 expected/expected_by_tool 解释。回归器冻结当前计划和策略预期，同时保留 baseline_expected，避免把合理的模式差异当成工具退化。

## 通用求解补充

1. 后执行空间 SMT 接受元数据一致、无采样、已完成的 symbolic modular 调用/断言轨迹。调用次数必须与符号后态次数一致；未知事件、循环事件、采样、未完成执行或不一致元数据继续拒绝进入本适配器。
2. 支持内建有限数组 full(p,n,l) 的符号列表：当 n 为已知、受预算约束的长度时，l 表示 n 个独立符号元素。没有选择具体值或将未知内容当成原数组。自由列表长度只能由前件约束，不能用后件缩小输入；存在列表在自己的断言作用域内展开。自由变量捕获、冲突长度、未知谓词、过长数组和不支持的析取保持 UNKNOWN。
3. 沿用原精确字节堆编码、完整局部环境等式、初始化/范围/对齐/分离约束、原始义务组绑定。所有原始 Coq 文件保持字节不变。本次没有修改或推送 sac 源码，也未改变在线执行和分支判断。

translation12 的空间 ON 现在为第一条完整断言生成合法字节堆反例；其他数组分解仍可为 VALID。后继错误合同状态对应的断言也可出现反例，但一项完整必要义务失效已足以拒绝整个模块化检查。该结论是合同检查，不能宣称真实 read 函数体执行错误。

## OFF 的完整反例证书

没有把原始辅助 split_goal 的反证当作父目标反证。新证书对整个 main_entail_wit_6 的两个分支构造反例，并保留原目标的精确关联：

- 对合法局部地址环境显式抽象整个父公式，并以内核检查的 original_parent_link 证明它在原地址处恰好等于原始父目标。
- 选择数组基址 4096、局部 zero 地址 8192。证明这两个区域正数、四字节对齐、在 32 位范围内且不重叠。
- 以真实字节堆构造数组 [0;1;2] 和 zero=1，证明满足完整空间前件、违反完整后件；同时反证父目标的另一个纯分支。
- 证明存在这种合法环境，因此模块化测试要求的“所有合法局部环境均满足父目标”不成立。

这是对程序局部环境全称闭包的完整反例，不是对含固定 opaque 全局地址参数的原始 Coq 命题声称无条件否定。原始命题、完整替换公式、关联定理、布局证明、字节堆、源码/VC 哈希全部保存；没有添加地址公理或把候选地址当假设塞进原文件。三个反例/布局定理仅保留其原类型中的 sizeof_* 参数或全局封闭，关联定理保留原 eval_addr_expr 参数；无新增证明公理，独立 coqchk 通过。

## 全量回归与成本

21 组、900 对输入，inline/modular 各跑空间 OFF/ON，共 3600 次原生执行。最终逐策略预期全部匹配：

| 配置 | PASS | FAIL | 预期 ERROR | UNKNOWN |
|---|---:|---:|---:|---:|
| inline OFF / ON | 498 | 379 | 23 | 0 |
| modular OFF / ON | 497 | 380 | 23 | 0 |

空间 ON 为原生自动结果。空间 OFF 使用原始完整目标哈希匹配的既有证明，以及本次新增 translation12 完整父目标反例。没有给旧证明重新计费。

新反例 ITP 共 2 次实际 gpt-6.1-sol 调用，857838 token；模型 220.703 秒、305.676 MiB，含所有失败/重试的 Coq 编译审计 14.716 秒、589.957 MiB，独立内核 127.404 秒、2101.969 MiB，总计 362.823 秒。第一次编译失败和第二次过严的“必须全局封闭”检查失败均保留；后者仅出现原类型参数，改为逐定理核对允许参数后，对相同候选重新编译审计和内核检查，没有新模型调用。此前完整父目标诊断的 5 次调用及成本继续单列引用。
